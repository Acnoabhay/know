## GitHub Pages deployment
1. Create a GitHub repository named **`Acnoabhay.github.io`**.
2. Upload the contents of this folder so that `index.html` is directly in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **`main`** and folder **`/ (root)`**, then save.
6. Your personal site should be available at **https://Acnoabhay.github.io/** after GitHub Pages finishes deploying.

If you instead use a normal repository name, the site URL will normally be:
`https://Acnoabhay.github.io/REPOSITORY-NAME/`
